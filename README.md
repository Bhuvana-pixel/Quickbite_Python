
1. About the Project

QuickBite is a food delivery application which operates in different cities. In this assessment, I worked as a Data Analyst to clean the given datasets, combine them and analyse the data to find useful business insights.

The main aim of this project is to understand the data and find how the business is performing. I have did this project using jupyter notebook so that i could check and validate the datasets each time and it was easy to combine at the last stage. 

2. Datasets Used

I was provided with six different datasets:

- Areas
- Customers
- Delivery Partners
- Feedback
- Orders
- Restaurants

All these datasets are related with each other using their IDs.

3. Data Cleaning

First, I checked all the six datasets to understand the data and identify the problems.

Some of the issues I found were:
- Duplicate records in some datasets.
- Missing values in different columns.
- Inconsistent city names and order status.
- Different formats in dates and text values.
- Inconsistent cuisine and vehicle type names.

I cleaned the data by removing duplicate records, handling missing values where required, standardizing text values and converting columns into proper data types.

After cleaning, I saved all six cleaned datasets into one Excel file named Quick_Bite_Data_Cleaning.xlsx.

4. Data Combining

After completing the cleaning process, I combined all six datasets using their common IDs.

I used the Orders dataset as the main dataset and joined the other tables to get the required information for each order.

I also created additional columns like:
- Order Date
- Order Time
- Order Day
- Is Late

The final combined dataset contains 1500 rows and 19 columns. I saved it as Quick_Bite_Combined_Data.xlsx.

5. Data Analysis

Using the combined dataset, I worked on the following three business questions.

1. Area Performance

I analysed the revenue generated by different areas and ranked them based on revenue. I also included delivered orders, average order value, average delivery time and late delivery rate to understand the performance of each area.

2. Top Cuisine by Day

I found which cuisine was ordered the most on each day of the week. I also calculated the order count and percentage share of each day's total orders.

3. Vehicle Performance

I compared the performance of different delivery vehicles by considering delivered orders, average delivery time, late deliveries and customer ratings. Orders taking more than 45 minutes were considered as late deliveries.

The results of all three questions are saved in Quick_Bite_Analysis.xlsx with separate sheets.
